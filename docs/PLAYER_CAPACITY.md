# v0.3.3 二十人及无尽扩展

本地旧版的容量、固定分组、并行轮选、联防及无尽玩法已移植到上游 v0.3.3（f07b8965）。
详细规则、安装/卸载与随上游更新的步骤见 [源码扩展说明](../extensions/20p-endless/README.md)。

普通插件 API 无法修改座位、房间协议或 Match 生命周期，因此这是独立管理的源码扩展。
基线保留四个官方版本切换、原生交互插件、皮肤以及外部 AI 接口；自定义玩法由用户授权。

旧版完整目录位于根目录的 `20人卫戍-Update/`，根仓库忽略它及其中的官方素材。
当前服务复用旧版的素材目录，不重写生成的数据表。验证记录见扩展目录的 `VALIDATION.md`。
